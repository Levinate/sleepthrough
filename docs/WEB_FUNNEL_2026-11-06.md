# Веб-воронка — 6 ноября 2026

Локальная версия: http://127.0.0.1:3191/ . На Railway и GitHub изменения не отправлялись.

Интерфейсы результата, плана, онбординга и ночной помощи используют общий с Android модуль `mobile/src/mvp.js`. `web-src/mvp-web.js` адаптирует маршруты, локальное хранение и существующий Supabase-аккаунт. Собрать изменённый общий модуль: `node build-web-mvp.mjs`.

Тест: 21 иллюстрированный экран в тёмной теме, один ответ — один переход. Прибавки +10/+15 и Sleep Score заменены профилем факторов. Проценты показывают долю сигналов среди отображённых факторов и ограничены 89%; это не вероятность причины или медицинский результат. Частота 1–2 / 3–4 / 5+ ночей даёт ориентир 2 / 4 / 6; цель на 28-ю ночь редактируется и не обещает результат.

Путь: результат → имя/email → три плана → согласие → явно демонстрационная оплата → 5 экранов онбординга → короткая экскурсия по реальным элементам кабинета. Есть вход и регистрация с подставленным email. Копирование локального плана в аккаунт предлагается отдельно; прогресс разных аккаунтов разделён.

Главное действие кабинета — янтарная I'm awake. Шаги: успокоение, действие по ведущему фактору, заметка на утро, дыхание 4/6 на 3 минуты с паузой/демо-пропуском, ориентир около 20 минут без таймера. Открытый эпизод возобновляется; отдельная кнопка создаёт новое пробуждение. Лог кнопки — нижняя граница числа пробуждений до утреннего чек-ина.

Утро: три ответа, сохранённая мысль, сравнение недель только по записанным ночам. В кабинете и дневнике используются собственные записи. Неизвестное время сна отображается прочерком. Демонстрационная отмена требует двух нажатий; пауза доступна на месяц. Даты окончания рассчитываются из выбранного плана.

**Stripe:** подключён к локальному Node.js-серверу в sandbox. Проверены настоящий Checkout на $27.99, серверная проверка возврата к онбордингу, пауза и отмена тестовой подписки. На Railway не опубликован. Детали и границы пилота: [STRIPE_SANDBOX.md](STRIPE_SANDBOX.md).

Проверено в браузере: 390 px без горизонтального переполнения, 21 вопрос, сохранение ответа, защита повторного нажатия, результат, email, блокировка checkout без согласия, все шаги онбординга, экскурсия, ночная заметка, чек-ин, перезагрузка, закрытие окна отмены и отмена, подстановка имени/email. Ошибок консоли при проверке не было. Дополнительно прошли проверки уроков, HTTP и изоляции/синхронизации аккаунтов, включая новый payload воронки.

Главный баннер сохранён. Обновлены title/meta, Privacy/Terms и футер; страница design notes остаётся по прямому адресу. Полное описание Android находится в `mobile/IMPLEMENTATION_0.5.0.md`.
